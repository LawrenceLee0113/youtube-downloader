# YouTube 下載器（Windows）

把 YouTube 連結下載成 **MP4 影片**（最高畫質、不重新壓縮）或 **MP3 音樂**（320kbps）。

## 下載

到 [Releases](https://github.com/LawrenceLee0113/youtube-downloader/releases/latest) 下載 `YTDownloader-windows.zip`，解壓縮到桌面或文件資料夾（不要放 `C:\Program Files`），打開 `YTDownloader.exe`。

- Windows 跳出 SmartScreen 警告：按「其他資訊」→「仍要執行」。
- 下載失敗：按「修復 / 更新下載引擎」再試一次。
- AV1 影片播不了：到 Microsoft Store 安裝免費的「AV1 Video Extension」，或用 VLC。

請只下載你有權利下載的內容。
